Student Management & University ERP System

A modular, enterprise-grade academic portal built with Spring Boot, MySQL, and responsive Bootstrap 5 architecture.

Java 17 LTS Spring Boot 3.3.4 Spring Security 6 MySQL 8.0 JDBC & Hibernate Thymeleaf Bootstrap 5.3.3
Domain: Java Web Application Development
Key Focus: Project Structure, Database Design, JDBC, & UI/UX
Rubric: Problem Understanding & Solution Design

Problem Statement & Solution Architecture

The Challenge
Traditional educational systems struggle with scattered paper records, manual attendance leakage, disparate grading spreadsheets, and lack of real-time student self-service portals.
The Proposed Solution
A unified three-tier ERP architecture featuring role-segregated portals:
• Admin Portal: Institute governance, master timetables & fee records.
• Faculty Portal: Dynamic QR attendance, grading, and assignments.
• Student Portal: QR scan attendance, marksheets, and digital ID card.
Rubric: Project Structure & Core Java

Modular Multi-Layered Architecture

Layered Structure
Strict separation of concerns adhering to SOLID principles:
• controller/: Request handling
• service/: Business logic
• repository/: Data persistence
• dto/: Clean request/response mapping
Core Java Features
• OOP: Polymorphism & Interfaces in Repositories
• Exception Handling: Centralized @ControllerAdvice
• Collections & Generics: Typesafe collections, Maps, and Optional
• Java Streams: Functional data filtering
Enterprise Security
• BCrypt password hashing
• Role-Based Access Control (RBAC)
• Custom Auth Handlers
• Secure Session & CSRF handling
Rubric: Database Design (28 Entities)

Relational Database Design & Schema

Normalized 3NF relational schema with strict Foreign Key integrity and automated auditing.

Domain Group Core Tables / Entities Key Relationships & Constraints
People & Auth users, students, teachers, tokens One-to-One with User, Unique emails, account verification tokens
Academics departments, courses, sections, subjects Hierarchical mapping: Dept → Course → Section → Subject
Classroom Operations attendance, qr_sessions, timetable_entries Composite uniqueness (Student + Subject + Date), Real-time QR expiration
Examinations & Finance marks, exam_results, fees, grievances Auto-calculated GPA, Transaction tracking, Ticket resolution logs
Rubric: Database Integration (JDBC)

Robust JDBC Connectivity & Operations

Dual Data Access Architecture
1. Direct JDBC Implementation:
• JdbcDatabaseConnection.java manages pooled & direct driver connections.
• StudentJdbcRepositoryImpl.java executes raw parameterized SQL queries with PreparedStatement and ResultSet.

2. Spring Data JPA & Hibernate:
• High-level ORM persistence with HikariCP connection pooling.
Live JDBC Diagnostics Endpoint
GET /api/diagnostics/jdbc/status Response: { "status": "SUCCESS", "jdbcConnected": true, "databaseProduct": "MySQL", "driverName": "MySQL Connector/J", "totalStudentsCount": 3 }

Prevents SQL Injection via prepared statement parameters and handles SQLException systematically.

Rubric: User Interface & Responsiveness

Modern UI/UX & Aesthetic Principles

100% Responsive Design
Bootstrap 5.3.3 grid system with offcanvas mobile navigations, collapsible sidebars, and adaptive tables for smart devices.
Modern Aesthetics

Rubric: Servlets & Web Integration

Servlets, RESTful APIs, & MVC Flow

Servlet Front Controller (DispatcherServlet)
Underneath Spring MVC, incoming HTTP requests route through the standard Java Servlet specification:
• Front Controller Pattern: DispatcherServlet receives client requests.
• Handler Mapping: Resolves URL to controller methods.
• View Resolver: Renders Thymeleaf templates with context models.
Web & Media Services
• Multipart File Uploads: Profile pictures, syllabus materials, and assignment docs.
• Server-side PDF Generation: Real-time marksheets, ID cards, and receipts via LibrePDF.
• RESTful APIs: JSON endpoints for mobile/AJAX integration under /api/**.
